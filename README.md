# BaaStard - My Opiniated Backend Runtime!
This Backend Runtime has been developed following certain opiniated decisions from my experience working with other BaaS such as *Supabase* and *Pocketbase*. 

**I am by no means saying that they're bad or that mine's better, probably is not**; it's just that I want something that works for me, I'd probably not use it for real production systems but it's still a cool project!

## 📦 Prerequisites
Ensure that you have the required dependencies:
* [Go v1.26.4](https://go.dev/doc/install)
* [Go Templ](https://templ.guide/quick-start/installation#go-install-as-tool) as Go Tooling
